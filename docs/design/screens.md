# 页面规格 · 贪食蛇 Snake

## S1 游戏主屏

```text
┌────────────────────────────────────┐
│  SNAKE // 贪食蛇          ● ONLINE │
│  [当前得分 000] [最高分 000] [状态] │
│  ┌──────────────────────────────┐  │
│  │                              │  │
│  │          Canvas 棋盘          │  │
│  │                              │  │
│  └──────────────────────────────┘  │
│  [ 开始 / 暂停 ]  [ 重新开始 ]      │
│  方向键 / WASD 移动 · 空格暂停       │
│         [ ↑ ] [ ← ↓ → ]            │
└────────────────────────────────────┘
```

### 入口与主操作

- 入口：直接打开 URL。
- 主操作：开始游戏；游戏中进行中可用空格暂停。
- 次操作：重新开始（立即重置并开始）。
- 键盘：方向键/WASD 转向；空格开始/暂停/继续；Enter 在结束时重开。
- 触摸：画布滑动转向；D-pad 按钮转向。

### 状态矩阵

| 状态 | 棋盘 | 覆盖层 | 得分 | 按钮 |
| --- | --- | --- | --- | --- |
| ready | 初始蛇 + 食物 | 标题/说明/开始 | 0 | 开始游戏可用 |
| running | 实时蛇/食物 | 无 | 实时 | 暂停可用 |
| paused | 冻结 | “已暂停” | 保留 | 继续/重开 |
| over | 定格 | “游戏结束” + 得分 | 保留 | 再来一局 |
| won | 定格 | “你赢了” | 保留 | 再来一局 |

### 响应式

| 断点 | 布局 |
| --- | --- |
| ≥ 641px | 单列卡片，最大宽 680px；D-pad 隐藏；显示键盘提示 |
| 360–640px | 卡片贴边 12px；D-pad 显示；按钮全宽；棋盘不溢出 |
| ≤ 359px | 仍保证棋盘宽度 ≥ 280px，记分板换行 |

> 以上为 CSS 实际阈值；验收视口固定为 360px、768px、1280px。360px 命中移动端规则，768px 与 1280px 使用桌面规则。

### QA 验收要点

- 开始后蛇会移动；方向键不会触发页面滚动。
- 食物不在蛇身上；吃到后分数 +10、长度 +1。
- 撞墙/撞自己后出现结算层，重开清空分数但保留最高分。
- 暂停后画面与分数冻结，继续后恢复。
- 手机宽度下无横向滚动，D-pad 可点击。
- 控制台无异常，Network 无外部请求。
