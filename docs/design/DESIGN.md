# 设计系统 · 贪食蛇 Snake

- 角色：顾知微（UI/UX）
- 方向：深夜街机厅的霓虹街机面板；深底、荧光绿蛇身、青色信息、克制的发光。

## 设计令牌

| Token | 值 | 用途 |
| --- | --- | --- |
| `--bg` | `#060913` | 页面背景 |
| `--panel` | `#0d1526` | 主面板 |
| `--panel-2` | `#111d33` | 次级面板/棋盘底 |
| `--line` | `#1e2d4a` | 边框/网格 |
| `--text` | `#e6edf7` | 主文本 |
| `--muted` | `#8fa3c0` | 次要文本 |
| `--lime` | `#a3e635` | 蛇身/主操作 |
| `--lime-deep` | `#65a30d` | 蛇身暗部 |
| `--cyan` | `#22d3ee` | 食物/高亮 |
| `--danger` | `#fb7185` | 结束/错误 |
| `--radius` | `18px` | 面板圆角 |
| `--space-1..5` | `4 / 8 / 16 / 24 / 32px` | 间距阶梯 |
| 字体 | `ui-monospace, "Cascadia Code", "SFMono-Regular", Consolas, monospace` | 街机/终端气质，避免外部字体 |

## 布局

- 单列居中：标题区 → 记分板（当前分 / 最高分 / 状态）→ 棋盘 → 操作按钮 → 操作说明。
- 棋盘正方形，宽 `min(92vw, 520px)`，内部绘制分辨率 600×600，CSS 等比缩放。
- 桌面端显示键盘提示；视口 ≤ 640px 时显示 4 向 D-pad，键盘提示仍保留。
- 按钮最小触控尺寸 44×44px；主按钮 lime 底深色字，次按钮描边。

## 状态与文案

| 状态 | 覆盖层 | 主按钮 |
| --- | --- | --- |
| ready | “贪食蛇” + 操作提示 | 开始游戏 |
| running | 无覆盖层；状态显示“进行中” | 暂停 |
| paused | “已暂停” + 按空格继续 | 继续 |
| over | “游戏结束” + 本局得分 | 再来一局 |
| won | “你赢了” + 满分提示 | 再来一局 |

## 可访问性

- Canvas `aria-label` 说明用途；状态与得分放在 `aria-live="polite"` 区域。
- 所有按钮有可见文本；图标方向键带 `aria-label`。
- 焦点环使用 cyan 2px，键盘可操作；空格/回车不触发页面滚动。
- 对比度：主文本/背景 ≥ 7:1，lime 按钮/深色文字 ≥ 7:1。
- `prefers-reduced-motion: reduce` 时关闭脉冲/过渡动画。

## 动效

- 食物轻微呼吸光晕（2s 循环）；撞车时结算层淡入；均可在减少动效模式下关闭。
- 不依赖动效传达状态；状态文本始终可见。
